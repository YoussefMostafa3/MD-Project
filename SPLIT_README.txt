MD Store - Split version
========================

This version separates inline CSS and JavaScript from the HTML pages.
The original project files/assets are otherwise kept intact.

Pages processed:
- MD Store/admin.html: 1 inline CSS block(s) -> css/admin.css; 1 inline JS block(s) -> js/admin.js
- MD Store/MD.html: 1 inline CSS block(s) -> css/style.css; 1 inline JS block(s) -> js/app.js

No backend files were modified.
